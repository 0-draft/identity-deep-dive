# 背景

## きっかけ

本件は、差分を取れる新しい版を持つ、活動中の作業部会ドラフト draft-ietf-wimse-http-signature-08 として選ばれた。選定時の注記によれば、本ドラフトに対して三つの新しい issue が立てられている。テストベクター（#419）、例における nonce のエントロピー（#420）、編集上のコメント（#417）である。Datatracker の状態は Active、Publication Requested、Submitted to IESG for Publication である。

## なぜ重要か

ドラフトは作業部会での手続きの終盤にあるため、-08 の変更は IESG のレビュー前に挙動を確定させる最後の機会である。-08 は、いくつかの緩い点を MUST にした。nonce の生成とエントロピー、登録済み問題タイプを伴う 400 と 501 のエラー挙動、TLS の使用、`wimse-aud` に対する Simple String Comparison である。CONNECT の例外も加わった。-08 に対して書かれた独立のテストベクターが WIMSE リストに投稿され、査読者が導入部へのコメントを送った。-07 の実装者は何が変わったかを確認する必要があり、検証実装を書く者は、共通の入力でテストできるようになった。

## 未解決の問題

- `keyid` と `alg` が存在する場合に、検証側が拒否するのか無視するのか。ドラフトは送信者が使ってはならないとだけ述べている（Section 3）。
- authority-form を対象とする CONNECT で、既定の `wimse-aud` が何になるか（Section 3、3.2）。
- 相手が problem details を受け付けない場合に、署名の「未対応」と「利用不能」をどう区別するか（Section 3.6）。
- 例の nonce に関する issue #420 が何を求めているか。提供された資料には、「説明用」という注記を提案するリストのスレッドしか示されていない。
- レビューで提案された導入部の文言（issue #417）が採用されるかどうか。-08 の Section 1 には含まれていない。
