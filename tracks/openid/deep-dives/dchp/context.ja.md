## なぜ重要か

このリポジトリは、OpenID Foundation の Digital Credentials Harmonized Presentation Working Group の作業領域であり、ISO/IEC JTC 1/SC 17（WG10）および DCP Working Group との共同の取り組みを支えている。目的は、ISO/IEC 18013-5 の Device Request / Device Response と OpenID for Verifiable Presentations の Authorization Request / Authorization Response を、ISO mdoc と IETF SD-JWT VC を含む対面およびオンラインの提示に向けて調和させることである。フィールド名や形が速く変わることは、Editor's Copy から実装する者に影響する。README は、この版が承認された Working Group Draft ではないと述べている。
