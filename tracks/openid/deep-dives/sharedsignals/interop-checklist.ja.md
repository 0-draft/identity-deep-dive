# Interop Checklist

- [ ] #368 のマージ済み差分を読み、どのイベント署名の仕組みが、どの仕様（SSF 1.1、CAEP 1.1、または両方）から削除されるのかを確認する。
- [ ] 1.1 の Receiver が、署名を持つイベントを含め、1.0 の Transmitter からのイベントを引き続き処理できることを確認する。
- [ ] 1.0 の Receiver が、#368 で削除されたものを省略した 1.1 の Transmitter からのイベントを拒否しないことを確認する。
- [ ] #355 がマージされた場合、SET の署名アルゴリズムについて合意できない Transmitter と Receiver を試験し、失敗が報告されることを確認する。
- [ ] Receiver が、理解できない複合サブジェクト（#366）やエージェントまたはワークロードのサブジェクト（#362）をどう扱うかを確認する。
- [ ] 任意のストリーム設定プロパティに JSON `null`（#369）を送り、Transmitter と Receiver の挙動が一致することを確認する。
- [ ] ブラウザーのオリジンから Transmitter メタデータと JWK Set を取得し、#367 で推奨されている CORS ヘッダーを確認する。
- [ ] CAEP Interoperability Profile の Receiver 要件（#315）と OAuth の節（#325）が、SSF 本文の要求と整合していることを確認する。
- [ ] #363 の仕様バージョンの節の改訂を踏まえ、Transmitter がどの仕様バージョン文字列を通知するかを確認する。
